# Yusuke Umehara — Academic Website

A Quarto academic website designed for GitHub Pages.

## Preview locally

```powershell
quarto preview
```

On this PC, the RStudio-bundled Quarto can be used:

```powershell
& 'C:\Program Files\RStudio\resources\app\bin\quarto\bin\quarto.exe' preview
```

Run `quarto render` to build the site into `docs/`. Before publishing, search for and replace `umeharayusuke`, `example.com`, `0000-0000-0000-0000`, and `20XX`.

See `OPERATIONS.md` for the Japanese setup and maintenance guide.
